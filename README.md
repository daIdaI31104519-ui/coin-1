## 基本方針

- 初期売買対象はBTC暗号資産FX。具体的な取引所・商品・損失上限は未決定。
- 市場理解・利益・Danger Zone（危険）の3研究分野は有力な構想。独立した3プログラムを作る決定ではない。
- 最終的な経済目的は、BTC FXで損失リスクと費用を管理しながら長期的な純利益を追求すること。市場理解は目的そのものではなく、そのための研究手段。
- 研究の入口は市場現象起点・損益／リスク起点などから選べる。初期研究順序や手法の優劣は未決定。従来の簡単な状態解釈→デモ→経験研究という初回循環も廃止しない。
- 研究・検証は制限の範囲で自動化できるが、本番戦略の採用や安全制約の緩和・実資金運用は独立した人間の承認が必要。
- PCまたはVPSで24時間・長期間の観測・研究・必要な運用を目指す。Telegramは補助窓口であり、24時間売買する意味ではない。
- 研究方法・構造は実証に基づき改善できるが、目的・安全境界と重要事項の承認を維持する。
- 研究、デモFX、本番取引の権限・資金・状態を分離する。
- 人間の原案、AIの解釈・追加提案、正式承認を混同せず、累積的な方向性の変化を確認する。
- 重要な設計変更、GitHub保存、main統合、実資金運用をそれぞれ別の承認として扱う。
